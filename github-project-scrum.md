## 🔀 Flujo de Trabajo (Gitflow)

```
main (producción)
  ├── release/v1.0.0 (releases)
  └── develop (staging)
       ├── feature/auth (features)
       ├── feature/dashboard
       ├── bugfix/login-error
       └── hotfix/password-reset
```

### Convención de Commits
```
feat: Nueva funcionalidad
fix: Corrección de bug
docs: Documentación
style: Formato de código
refactor: Refactorización
test: Pruebas
chore: Mantenimiento
```

## 📌 Cómo usar este Tablero

### Movimiento de Tareas

1. **Tarea Nueva** → Se crea en **To Do**
2. **Asignación** → Se etiqueta con `Sprint #X` y `Story Points`
3. **Inicio** → Se mueve a **In Progress** + se asigna responsable
4. **Actualización** → Daily Standup reporta progreso %
5. **Completada** → Se mueve a **Done** + Se registra fecha finalización
6. **Release** → Sprint Review aprueba y prepara para producción

### Etiquetas Usadas
- `Sprint #1`, `Sprint #2`, `Sprint #3`, `Sprint #4`
- `Frontend`, `Backend`, `DevOps`, `Testing`, `Documentation`
- `bug`, `enhancement`, `documentation`, `high-priority`
- `blocked`, `review-needed`, `testing`
